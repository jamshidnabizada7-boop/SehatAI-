## Data and migrations

Clean migration deployment initially failed Care seed because five fields existed in the committed Prisma schema but not migrations. Additive migration `20261024000000_jurisdiction_approval_fields` adds legal/human approval fields and default domestic scope. It does not invent approval records or enable cross-border corridors. Applied only to a new loopback PostgreSQL 18 database; both seeds succeeded. On rollback, normally retain additive columns so existing data is not destroyed; coordinate any later column removal separately.

New test fixtures are synthetic. Financial tests and production verifier explicitly reject non-loopback/non-test databases. Existing legacy test programs do not all contain that protection: always point the whole suite at disposable data.

## Remaining release limitations

- Clinical rules remain deterministic, context heuristics remain imperfect, and qualified clinical review is required. Subject-specific resolution and spelling coverage are not a complete clinical NLP system. Passive ideation is represented separately from possible imminent intent, but both conservatively retain urgent safety guidance.
- The corpus and all patient-facing educational subfeatures were not exhaustively clinically revalidated. Citation presence verifies an allowed source identity, not sentence-level medical entailment, freshness or legal applicability. No “zero hallucination” claim is justified.
- No live AI, voice, vision, video, SMTP/push, external storage, real payment or production network failover was exercised. Consent, vendor contracts, retention/deletion, encryption key lifecycle and jurisdiction approvals require owner review.
- Browser health snapshots are tab-scoped plaintext sessionStorage; anyone with access to that browser tab/device may read them. Guest history uses a high-entropy bearer token; an HttpOnly server-issued guest session remains an architectural improvement. Quota failure is visible; storage is not guaranteed.
- Notifications created inside financial transactions require a running outbox worker. They are committed atomically, not guaranteed delivered.
- Dependency audit is reduced from 109 findings to two advisory groups: `deepmerge-ts` below 8 (Prisma CLI config dependency, high stack-exhaustion advisory) and old nested `uuid` (moderate buffered v3/v5/v6 advisory). Avoid unreviewed major overrides; owner must resolve or document reachable-risk acceptance. No critical advisory remains in this audit snapshot. See `work/audit-final.json` for exact advisories.
- Afghanistan resource records and legal corridors were not newly verified. The dashboard retains existing benchmark presentation exactly as requested; its pre-existing hardcoded/displayed metrics were not independently established as live production measurements.
